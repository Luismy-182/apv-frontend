
# APV - Frontend

Aplicación web para la gestión de pacientes veterinarios.

Interfaz construida en React que consume una API REST desarrollada en Node.js.

## 🧠 Arquitectura
- Componentes reutilizables
- Manejo de estado con Context API
- Consumo de API con Axios / Fetch
- Routing con React Router

## ✨ Funcionalidades
- Registro e inicio de sesión
- Gestión de pacientes
- Creación y edición de citas
- Eliminación de registros
